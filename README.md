# Home4Live

This is a web application for a home renovation and construction company at [https://home4live.ca](https://home4live.ca).

## Tech Stack

- **Framework:** React 19
- **Build Tool:** Vite 7 (with `@vitejs/plugin-react-swc` & `vite-plugin-image-optimizer`)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4 & Lucide React
- **Routing:** React Router v7
- **Form Management:** React Hook Form & Zod
- **SEO & Meta:** React Helmet Async
- **Email:** Resend API
- **Security:** Cloudflare Turnstile

## Available Scripts

In the project directory, you can run:

### `npm run dev`

Runs the app in development mode.
Open [http://localhost:8080](http://localhost:8080) to view it in the browser.

### `npm run build`

Builds the app for production to the `dist` folder with image optimization.

### `npm run build:dev`

Builds the app using development mode flags.

### `npm run preview`

Serves the production build locally for preview.

### `npm run lint`

Runs ESLint across the codebase.

## Installation and Setup

1. **Clone the repository:**
   ```sh
   git clone https://github.com/alibakhtiari/home4live.git
   ```
2. **Navigate to the project directory:**
   ```sh
   cd home4live
   ```
3. **Install dependencies:**
   ```sh
   npm install
   ```
4. **Start the dev server:**
   ```sh
   npm run dev
   ```
